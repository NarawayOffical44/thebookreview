# thebookreview

One-page site where early readers report issues in *The Deleted Line* (chapter, page, issue) and see if someone already reported it.

- Page: `site/index.html` (settings at the top of its script)
- Storage: JSONBin (hosted JSON)
- Hosting: Render static site, publish directory `site`
- Setup steps: `SETUP.md` · Tests: `npm test`
